# GunOnUrKeyboard

Небольшое приложение для Виндовс(Пока что). каждое нажатие клавиши воспроизводит звук выстрела и уменьшает счётчик патронов внизу экрана.

## Установка и запуск

ВАЖНО: `Нужен установленный Python 3.14+ и Git`,
также нужно запускать Python файл из папки `GunOnUrKeyboard\Windows(Или linux)`, потому что скрипт ищет звуки в текущей папке. Оставьте открытым окно терминала, из которого оно запущено.

- 1 Установка файлов из репо.:
```
git clone https://github.com/WOYRK2/GunOnUrKeyboard
```

- 2 Перейдите в папку с репо.:
```
cd GunOnUrKeyboard
```

- 3 Установите зависимости:
```
pip install pynput PySide6
```

- 4 Запуск:
```
cd GunOnUrKeyboard/Windows
py main.py
```
